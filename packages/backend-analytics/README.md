# Backend продуктовой аналитики

Пакет принимает ограниченные события через BullMQ, сохраняет их отдельно от аудита и возвращает
внутреннему API только агрегаты. Публичный API-контроллер расположен в `apps/backend/src/analytics`
и требует клиентскую сессию; внутренний маршрут требует `InternalSession` и разрешение
`product_analytics`.

`ProductAnalyticsService` проверяет разрешённые сочетания типа события и свойств, ставит событие в
очередь, выполняет агрегирование и пакетное удаление записей старше 90 дней. Worker сохраняет строки
с идемпотентностью по случайному `eventId` и запускает очистку по расписанию и при старте. В таблице
нет пользовательских, корпоративных и заведений идентификаторов; точные границы данных заданы в
`MVP_SCOPE.md` и `DATA_MODEL.md`.
