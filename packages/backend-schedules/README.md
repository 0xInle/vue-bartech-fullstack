# Backend графика сотрудников

Пакет `@bartech/backend-schedules` реализует предметные операции планового графика. `SchedulesService` читает месячные строки по интервалам членства и должностей, валидирует изменения ячеек, хранит историю значений и комментариев, назначает версии циклических шаблонов, формирует и продлевает план. `ScheduleExportService` готовит PDF и XLSX выгрузки.

Пакет экспортирует NestJS-модуль для подключения в HTTP API. Проверка текущего пользователя и права `view_schedule`/`manage_schedule` остаются на API-слое; сервисы работают с уже определёнными company/venue идентификаторами и дополнительно проверяют членство для операций записи. Полные правила — в [`EMPLOYEE_SCHEDULE.md`](../../EMPLOYEE_SCHEDULE.md).
