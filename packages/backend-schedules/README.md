# Backend графика сотрудников

Пакет `@bartech/backend-schedules` реализует операции планового графика. `SchedulesService` читает месячные строки, проверяет настройки и значения смен, сохраняет историю и комментарии, ведёт версии циклических шаблонов и формирует или продлевает план. `ScheduleExportService` готовит выгрузки PDF и XLSX с кодом смены, временем начала и длительностью.

Настройки типов принадлежат заведению. Четыре кода фиксированы, а ячейка хранит снимок типа, начала и длительности, а также ID выбранной настройки, если она была выбрана. Снимок остаётся главным: изменение настройки не меняет уже заполненную смену, а удаление настройки очищает только ссылку. Версия цикла хранит упорядоченные ID вариантов смен и выходные. Сервис принимает идентификаторы компании и заведения, ограничивает данные этим контекстом и дополнительно проверяет членство для операций записи. Проверка сессии и разрешений остаётся на HTTP-слое. Полные правила приведены в [`EMPLOYEE_SCHEDULE.md`](../../EMPLOYEE_SCHEDULE.md).
