# Файловое хранилище backend

Пакет `@bartech/backend-files` предоставляет backend-модулям интерфейс `FileStorage` и адаптер
закрытого S3-совместимого хранилища. В MVP конфигурация указывает на Yandex Object Storage;
адаптер загружает и удаляет объекты и выдаёт подписанную ссылку скачивания с именем вложения.

Модуль не принимает решений о доступе к продуктам или сроке жизни выгрузок. Эти правила остаются
в `backend-exports`, который передаёт только server-generated ключ и короткий TTL. Метод `get`
возвращает поток приватного объекта для серверной обработки; `backend-support` использует его для
передачи карантинного вложения сканеру. Этот метод не выдаёт пользователю доступ к файлу. Секреты
хранятся в окружении backend и не попадают в объектные ключи или журнал действий.
