# Управление локальной командой

`TeamService` отвечает за изменение должности и делегированных прав сотрудника в одном заведении. Он повторно загружает текущую команду в транзакции, сериализует изменения блокировкой строки заведения, проверяет полномочия инициатора и ограничения перехода, сохраняет результат и пишет события `AuditEvent` атомарно.

Делегируются только перечисленные в `PermissionService` операционные права. Изменение должности сбрасывает делегированные права только в текущем заведении. Назначение нового бар-менеджера прекращает временную ответственность в этом заведении. Самоизменение через карточку запрещено; выход, удаление и отдельные сценарии передачи управления остаются за границами сервиса.

HTTP-контракт расположен в `apps/backend/src/organizations/team.controller.ts`, список команды и допустимых действий читается через `OrganizationsService`. Бизнес-правила определены в `ROLES_AND_PERMISSIONS.md`.
