# Управление локальной командой

`TeamService` отвечает за изменение должности и персональных разрешений сотрудника в одном заведении, а также за плановое увольнение. Увольнение принимает первый нерабочий день, который хранится как исключительная граница `endedOn`. В одной транзакции сервис проверяет права и непрерывность управления по всем уже запланированным уходам, очищает график с даты увольнения с записью истории и создаёт событие `AuditEvent`. Строки заведения и членства блокируются, чтобы сериализовать увольнение с изменениями графика.

`VenuePermissionOverride` хранит явные включения и отключения разрешений; остальные значения наследуются от текущей должности. Смена должности удаляет переопределения и восстанавливает значения новой роли. Дополнительные операционные права по-прежнему ограничены разрешениями назначающего и правилами должностей. Назначение нового бар-менеджера прекращает временную ответственность в этом заведении. Самоувольнение запрещено; запланированное увольнение не удаляет настройки разрешений или временную ответственность заранее — дата доступа ограничивается состоянием членства.

HTTP-контракт расположен в `apps/backend/src/organizations/team.controller.ts`, список команды и допустимых действий читается через `OrganizationsService`. Бизнес-правила определены в `ROLES_AND_PERMISSIONS.md`.
