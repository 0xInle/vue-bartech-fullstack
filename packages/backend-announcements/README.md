# Объявления заведения

Пакет хранит общие объявления одного заведения и предоставляет сервис их чтения, создания,
редактирования и удаления. HTTP-контроллер подключается в `apps/backend`; он проверяет членство в
выбранном заведении и `manage_venue` для мутаций. Репозиторий ограничивает все операции парой
`companyId`/`venueId` и атомарно записывает аудит вместе с изменением объявления.

Основные правила: `docs/superpowers/specs/2026-11-17-venue-announcements-design.md`. Интерфейсный
сценарий Главной описан в `UI_AND_NAVIGATION.md`.
