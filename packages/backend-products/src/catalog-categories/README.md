# Управление категориями ингредиентов

Модуль предоставляет внутреннему backoffice управление общим деревом системных категорий
ингредиентов. Он отвечает за создание, редактирование, порядок и активность категорий, проверяет
ограничения дерева под транзакционной блокировкой и записывает каждое изменение в оба журнала аудита.

`CatalogCategoriesService` проверяет иерархию и защищает системную категорию `other`;
`CatalogCategoriesRepository` выполняет чтение и транзакционные записи. API модуля подключается
только под внутренними маршрутами с `global_catalog`. Полные продуктовые правила приведены в
спецификации `docs/specs/2026-10-17-stage-9-ingredient-category-management-design.md`.
