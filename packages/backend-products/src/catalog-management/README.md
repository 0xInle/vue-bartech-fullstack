# Управление глобальным каталогом

Модуль управляет существующими глобальными карточками ингредиентов и используется только внутренним
API, защищённым сессией `InternalUser` и разрешением `global_catalog`. Он не открывает данные
компаний, заведений или рецептур.

`CatalogManagementService` проверяет активность карточки для редактирования, вычисляет нормализованные
поля по правилам `catalog-review`, управляет состояниями алиасов и готовит preview слияния.
`CatalogManagementRepository` ограничивает выборки глобальными ингредиентами, считает ссылки и
блокирует строки перед конкурентными изменениями.

При слиянии сотрудник выбирает активную каноническую карточку и активный или архивный дубликат.
Сервис повторно проверяет обе версии и конфликты, дополняет пустые поля, переносит алиасы и все
глобальные ссылки `ProductComponent`, удаляет дубликат и записывает события в оба аудита в одной
Prisma-транзакции. Правила алиасов и переноса описаны в `DATA_MODEL.md`, интерфейс — в
`UI_AND_NAVIGATION.md`.
