# Чтение продукции для выгрузки

`ProductExportReadService` предоставляет backend-модулю выгрузок read-only снимки одной или
нескольких карточек и продукции одного заведения. Репозиторий явно ограничивает чтение парой
компания/заведение и включает только связанные единицы, справочные значения, категории и снимки
глобальных ингредиентов, на которые ссылается локальный состав.

Сериализуемый контракт исключает идентификаторы аккаунтов и авторов. Полномочия пользователя и
доступ к архиву проверяет `backend-exports` перед запросом; этот API не является HTTP endpoint и
не заменяет проверки доступа самого продукта.
