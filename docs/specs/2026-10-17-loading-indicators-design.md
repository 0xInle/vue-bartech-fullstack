# Единая индикация загрузки в интерфейсе

## Цель

Показывать пользователю явный визуальный признак ожидания вместо текстовых сообщений «Загружаем…» и похожих заглушек. Индикатор использует зелёный основной цвет приложения, как основные кнопки.

## Область изменений

- Состояния ожидания сессии и рабочего пространства при открытии и смене страниц.
- Первичная загрузка данных экранов: списков, карточек, приглашений и других данных, для которых сейчас показывается текстовое сообщение загрузки.
- Загрузка данных, необходимых открытому Drawer или Dialog. Индикатор показывается только пока эти данные действительно запрашиваются; Drawer с уже подготовленным содержимым не задерживается искусственно.
- Индикаторы загрузки действий внутри кнопок остаются без изменений.

## Поведение

- Для ожидания данных отображается PrimeVue `ProgressSpinner` вместо информационного `Message` с текстом «Загружаем…».
- Цвет индикатора берётся из основного зелёного цвета PrimeVue-темы приложения.
- Индикатор имеет доступное имя для вспомогательных технологий.
- Существующие условия загрузки и обработка ошибок сохраняются: spinner показывается только в состоянии первичной загрузки, а ошибка продолжает отображаться отдельно.
- При загрузке страницы, крупного основного блока или результатов поиска увеличенный индикатор показывается по центру окна поверх содержимого. При загрузке небольших частей формы или отдельной секции сохраняется компактный индикатор на месте.
- Информационные сообщения, пустые состояния, статусы операций и ошибки не заменяются индикатором.
- Не добавляется искусственная задержка при переходе между страницами. Полноэкранный индикатор включается только пока страница, крупный блок или поиск действительно ожидают данные.

## Технические границы

- Переиспользовать общий компонент состояния загрузки с компактным и полноэкранным режимами; не менять бизнес-логику запросов, кэширование и серверные контракты.
- Не менять продуктовые правила, разрешения и навигацию.
- Не добавлять новые зависимости и тестовую инфраструктуру.

## Проверка

- Выполнить форматирование затронутых файлов.
- Запустить разрешённые статические проверки, если область изменений позволяет их выполнить без воздействия на посторонние файлы.
- Не запускать тесты, typecheck, локальный сервер или браузерную проверку без отдельной команды пользователя.
