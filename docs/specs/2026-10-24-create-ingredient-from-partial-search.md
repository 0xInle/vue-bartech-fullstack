# Создание ингредиента при частичных результатах поиска

## Цель

Дать пользователю возможность начать создание локального ингредиента, если поиск вернул похожие позиции, но среди них нет нужной.

## Поведение

- После завершения поиска в подвале AutoComplete показывается действие создания, в том числе если среди результатов есть точное совпадение по нормализованному названию для типа `INGREDIENT`.
- Похожие результаты остаются доступны для выбора; действие создания находится в подвале, за пределами списка опций.
- При нулевой выдаче сохраняется текст «Ингредиент не найден». При частичных результатах показывается подсказка «Не нашли нужное?» перед действием «Создать ингредиент».
- Нажатие действия заменяет его существующей компактной формой, подставляет текущий запрос в поле названия и требует выбрать категорию перед добавлением.
- При отправке формы сервер повторно проверяет нормализованное название среди глобальных ингредиентов и локальных ингредиентов текущего заведения; при совпадении запись не создаётся, пользователю показывается сообщение.
- Поведение применяется к общему поиску компонентов коктейлей, заготовок и гарниров; проверка выполняется на сервере для всех входов создания.

## Решение

Выбран вход в форму по одному нажатию. Автоматическое сохранение с категорией по умолчанию не используется: категория обязательна и остаётся осознанным выбором пользователя.

## Ограничения

- Сохранять текущую обработку загрузки, ошибок и выбора существующего результата.
- Не допускать дубликаты локальных ингредиентов и глобального каталога.
- Сверять оформление с `UI_COMPONENT_STYLES.md` и одобренными образцами.
- Выполнить визуальную проверку в браузере; тесты не добавлять и не запускать без отдельной команды.
