# Поведение блоков на главной

## Намерение

Убрать адаптивное ограничение высоты карточек. Главные блоки занимают место по содержимому, чтобы
строки и карточки не обрезались при переключении ширины экрана.

## Правила

- Все блоки раскрыты по умолчанию и могут сворачиваться пользователем.
- Сворачивание и раскрытие блоков сопровождается плавной анимацией; учитывается настройка уменьшения
  движения в системе.
- Карточки не получают общий предел высоты и не растягиваются, чтобы заполнить пустое пространство.
- Калькулятор целиком растёт по содержимому.
- «Последние изменения» показывает три последние записи.
- Задачи, чек-листы и объявления показывают внутреннюю прокрутку, если в списке больше десяти записей;
  при десяти записях и менее список отображается целиком.
- На широком экране блоки остаются в двух колонках; на узком — располагаются в одной колонке и
  прокручиваются вместе со страницей.

## Подход

Удалить ограничения высоты и прокрутку, добавленные для всех карточек в адаптивной раскладке. Оставить
локальный предел прокрутки только для длинных списков, включать его по количеству записей. Для
сворачивания использовать общую CSS-анимацию, не меняющую размеры содержимого в раскрытом состоянии.

## Вне объёма

Порядок блоков, данные, права, названия, пустые состояния и бизнес-логика не меняются. Тестовые записи
не создаются.
