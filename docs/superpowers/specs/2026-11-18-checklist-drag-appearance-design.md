# Перетаскивание пунктов чек-листа

## Цель

Сделать перестановку пунктов предсказуемой и визуально согласованной с редактором: ручка перетаскивания находится рядом с номером и полем пункта, однострочное поле остаётся компактным, а перемещаемая строка остаётся читаемой без белой карточки.

## Решение

Для сортировки используется `vue-draggable-plus` с одним списком и двусторонней привязкой `v-model`. Перетаскивание начинается только за ручку рядом с номером. Библиотека работает в fallback-режиме: перемещаемая копия остаётся видимой и читаемой, но фон, рамка и тень убраны; поле ввода в копии тоже прозрачное. Браузерное выделение отключено на строках списка и перетаскиваемой копии, а выделение текста внутри поля ввода сохранено. Placeholder не показывает содержимое и не имеет отдельного индикатора позиции. Второй список, межсписочное перемещение и изменение API не нужны.

После перемещения порядок остаётся в массиве черновика и сохраняется в существующем порядке пунктов. Нумерация пересчитывается по позиции. Поля, удаление, добавление и фокус нового пункта, ограничения и формат данных API остаются прежними.

## Границы

- Удалить PrimeVue `DataTable` row-reorder и самописную обработку native drag image.
- Не менять валидацию, состав данных, права, API или сервер.
- Не добавлять другие зависимости.
- Не запускать браузерную проверку; визуально проверить результат может пользователь.

## UI-сверка

Используются однострочный `InputText`, кнопки PrimeVue и токены темы приложения. Табличный образец `TeamMembersTable.vue` задаёт компактную плотность строк; список чек-листа сохраняет однострочную компоновку формы и не превращается в DataTable.
