# Предпросмотр продукции из поиска

## Задача и цель

Пользователь должен иметь возможность быстро открыть карточку коктейля, заготовки или гарнира
непосредственно из результатов поиска на Главной, не покидая экран поиска. Для продукции текущего
заведения карточка также должна сохранять доступное пользователю действие редактирования.

## Согласованный вариант

В строке подходящего результата рядом с названием показывается декоративная иконка PrimeIcons
`pi-arrow-up-right`. Строка целиком кликабельна и открывает Drawer без перехода со страницы поиска.

- Для продукта текущего заведения открывается соответствующий штатный Drawer карточки коктейля,
  заготовки или гарнира. Он показывает действие «Редактировать» только при наличии разрешения
  `manage_products`; форма редактирования открывается поверх текущего экрана, без перехода на страницу
  каталога.
- Для продукта другого заведения в поиске по компании открывается Drawer только для чтения. Текущее рабочее
  пространство не переключается.
- Иконка не показывается у глобальной продукции и ингредиентов.

Результат поиска содержит `scope` (`VENUE` или `GLOBAL`), тип и идентификатор заведения. Эти данные
используются для определения доступного сценария; сервер остаётся источником проверки прав.

## Рассмотренные подходы

1. **Иконка рядом с названием и Drawer по нажатию на строку — выбранный вариант.** Не
   переводит пользователя на страницу каталога и повторяет её существующую карточку.
2. **Drawer только по отдельному действию у иконки, а строка сохраняет переход.** Отклонён после проверки
   интерфейса: клик по найденной заготовке неожиданно уводил со страницы поиска.
3. **Открывать Drawer для любого результата.** Отклонён, поскольку для ингредиентов и глобальной
   продукции этот сценарий не предусмотрен.

## Границы

- Менять поведение строки только для локальных коктейлей, заготовок и гарниров на Главной; другие
  результаты сохраняют прежнее поведение.
- Не показывать просмотр для ингредиентов и глобальной продукции.
- Не разрешать редактирование продуктов другого заведения.
- Использовать декоративную иконку `pi-arrow-up-right` рядом с названием; действие выполняет вся строка.

## Материалы и критерии готовности

- Кодовые образцы: `apps/web/app/features/cocktails/components/CocktailCardDrawer.vue`,
  `apps/web/app/features/preparations/components/PreparationCardDrawer.vue`,
  `apps/web/app/features/garnishes/components/GarnishCardDrawer.vue`,
  `apps/web/app/features/products/components/ProductSearchResultDrawer.vue` и кнопки действий в
  `CocktailListScreen.vue`.
- Интерфейс сверяется с правилами `UI_COMPONENT_STYLES.md` и сценариями поиска и карточек в
  `UI_AND_NAVIGATION.md`.
- Проверить кликом по строке текущего заведения открытие локальной карточки и наличие/отсутствие
  редактирования по правам; в поиске компании проверить Drawer продукта другого заведения только для чтения.
- Убедиться, что глобальные продукты и ингредиенты сохраняют прежнее поведение.
