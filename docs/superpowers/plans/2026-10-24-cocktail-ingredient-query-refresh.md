# Обновление формы создания ингредиента — план реализации

> **Для исполнителя:** следовать плану по шагам; ограничения проекта применяются ко всем шагам.

**Цель:** после закрытия поиска новая inline-форма локального ингредиента должна подставлять актуальный запрос, а текст «Ингредиент не найден» должен быть компактнее.

**Архитектура:** использовать событие скрытия PrimeVue `AutoComplete` через существующий компонент `IngredientSelector`, чтобы сбрасывать состояние формы при закрытии подсказок. При повторном нажатии «Создать ингредиент» инициализировать имя текущим запросом. Состояние уже открытой формы не синхронизировать с последующими изменениями поиска.

**Технологии:** Vue 3, PrimeVue 4, TypeScript, Tailwind CSS.

**Спецификация:** `docs/specs/2026-10-24-cocktail-ingredient-create-query-refresh.md`.

## Общие ограничения

- Менять только поток создания локального ингредиента в коктейле и вспомогательный текст отсутствия результатов.
- Не менять запрос поиска, API и серверную логику создания ингредиента.
- Не создавать и не запускать тесты; визуальную проверку в браузере выполняет пользователь.
- Сохранять текущие изменения рабочей копии.

## Файлы

- `apps/web/app/features/products/components/IngredientSelector.vue` — пробросить наружу событие скрытия оверлея поиска.
- `apps/web/app/features/cocktails/components/CocktailComponentRows.vue` — сбросить активную форму при закрытии подсказок и уменьшить подпись отсутствия результатов.

## Области внимания

- Закрытие поиска кликом снаружи сбрасывает открытую форму.
- Повторное открытие формы использует актуальный поисковый текст.
- Ручная правка названия не меняется, пока форма остаётся открытой.
- Скрытие списка категорий не должно закрывать форму создания ингредиента.
