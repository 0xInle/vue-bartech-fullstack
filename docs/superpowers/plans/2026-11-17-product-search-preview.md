# Предпросмотр продукции из поиска — план реализации

> **Для исполнителя:** выполнять шаги по порядку, сверяясь с дизайн-документом и кодовыми образцами.

**Цель:** дать возможность открыть Drawer коктейля, заготовки или гарнира прямо из поисковой выдачи,
сохранив существующий клик по строке и ограничения редактирования.

**Архитектура:** результаты поиска показывают декоративную иконку только у локальной продукции типов
`COCKTAIL`, `PREPARATION` и `GARNISH`. Выбор строки открывает штатную карточку текущего заведения или
карточку продукта другого заведения только для чтения.

**Стек:** Vue 3, Nuxt, TypeScript, PrimeVue 4, Vue Query.

**Дизайн:** `docs/superpowers/specs/2026-11-17-product-search-preview-design.md`

## Общие ограничения

- Не менять API и серверную модель поиска; использовать существующие `scope`, `type`, `id`, `venueId`.
- Глобальные результаты и ингредиенты не получают иконку просмотра.
- Просмотр продукта другого заведения остаётся только для чтения; рабочее пространство не переключается.
- Редактирование локального продукта показывается только при `manage_products`.
- Сохранять прежнее поведение строк для остальных типов, тестовую инфраструктуру и зависимости; тесты не
  создавать и не запускать.
- Перед реализацией сверить `UI_COMPONENT_STYLES.md`, сценарии поиска/карточек в `UI_AND_NAVIGATION.md`
  и все образцы, перечисленные в дизайн-документе.

## Файлы и ответственность

- `apps/web/app/features/products/components/WorkspaceProductSearchResults.vue` — декоративная иконка
  просмотра и условие её показа.
- `apps/web/app/features/products/components/WorkspaceProductSearch.vue` — выбор карточки,
  открытие подходящего Drawer и существующего редактора для текущего заведения.
- `apps/web/app/features/cocktails/components/CocktailCardDrawer.vue`,
  `apps/web/app/features/preparations/components/PreparationCardDrawer.vue`,
  `apps/web/app/features/garnishes/components/GarnishCardDrawer.vue` — передача загруженной карточки
  редактору при сохранении существующего события `edit` для экранов каталогов.
- `UI_AND_NAVIGATION.md` — зафиксировать просмотр из выдачи и сохранить действующие правила выбора строки.

## Проверка рисков

- `scope === 'GLOBAL'`: иконки нет; прежнее поведение строки сохраняется.
- Тип `INGREDIENT`: иконки нет; существующий поиск ингредиентов не меняется.
- Локальный продукт текущего заведения без `manage_products`: карточка открывается, действия изменения
  отсутствуют.
- Локальный продукт текущего заведения с `manage_products`: карточка и редактирование доступны через
  штатные Drawer; переход на страницу не происходит при открытии просмотра.
- Локальный продукт другого заведения в поиске компании: открывается Drawer только для чтения; текущий
  контекст остаётся прежним.
- Клик по допустимой локальной строке открывает Drawer; соседняя иконка декоративная и не имеет
  отдельного обработчика. Остальные строки сохраняют прежнее поведение.
