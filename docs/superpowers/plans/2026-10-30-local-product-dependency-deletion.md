# Замена и каскадное удаление локальных товаров: план реализации

> **Для исполнительных агентов:** выполнить план поэтапно, отмечая чекбоксы. Не запускать тесты или браузерную проверку без прямого разрешения пользователя.

**Цель:** реализовать замену локального товара в активных прямых ссылках либо атомарное удаление его локальной зависимой цепочки; при отсутствии зависимостей оставить короткое подтверждение.

**Архитектура:** Расширить общий серверный сервис архива/удаления, чтобы строить версионированный план по графу локальных продуктов и выполнять выбранную операцию в транзакции с повторной проверкой прав и графа. Использовать этот API из общего UI подтверждения; добавить доступ к активным локальным ингредиентам через отдельный список в группе «Каталог».

**Стек:** Nuxt 4, Vue 3, PrimeVue, NestJS, Prisma/PostgreSQL, OpenAPI и сгенерированный `@bartech/api-client`.

**Спецификация:** `docs/specs/2026-10-30-local-product-dependency-deletion.md`.

## Общие ограничения

- Удаляются только локальные продукты текущего заведения типов `COCKTAIL`, `PREPARATION`, `INGREDIENT`, `GARNISH`.
- Глобальные продукты никогда не удаляются; активный глобальный ингредиент допускается только как выбранная замена, если разрешён правилами состава.
- Замена меняет только явно выбранные прямые ссылки активных карточек. Архивные карточки не изменяются.
- Каскадное удаление включает цель и все локальные прямые/транзитивные зависимые карточки; компоненты, которые лишь входят в эти карточки, остаются.
- Простое удаление без зависимостей подтверждается коротким Dialog без ввода названия. Для каскада требуется точное название исходной карточки.
- Сохранять существующие изменения рабочего дерева. Не создавать и не запускать тесты, не запускать typecheck/browser/server без команды пользователя.
- Перед UI-изменениями сверить `UI_COMPONENT_STYLES.md`, сценарии `UI_AND_NAVIGATION.md` и образцы списков, карточек, архивирования и восстановления.

## Фокус проверки

- Цель используется несколькими активными карточками или несколько раз в одной карточке: все прямые использования показаны, операция не теряет ссылки.
- Зависимость транзитивна: план каскада включает все локальные карточки обратного замыкания, но не соседние компоненты.
- Есть архивная зависимость: замена не изменяет архив, каскад показывает её и удаляет только после явного подтверждения.
- Цепочка содержит глобальный ингредиент как компонент: глобальный товар не попадает в набор удаления.
- Граф, право или принадлежность меняются после загрузки плана: сервер отказывает и требует обновить план.
