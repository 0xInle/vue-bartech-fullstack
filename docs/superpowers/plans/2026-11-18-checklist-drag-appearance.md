# План реализации перетаскивания пунктов чек-листа

**Цель:** заменить сортировку PrimeVue `DataTable` на `vue-draggable-plus`, сохранив существующий пользовательский сценарий редактора чек-листа.

**Архитектура:** один `VueDraggable` с `v-model` над существующим массивом черновика. Перестановка меняет порядок черновика; существующий код валидации и сохранения остаётся источником правил и формата API. Используется fallback-перетаскивание с читаемой копией пункта на прозрачном фоне; пустой placeholder отмечен зелёной линией вставки.

**Технологии:** Vue 3, Nuxt 4, PrimeVue 4.5.5, `vue-draggable-plus`.

**Дизайн:** `docs/superpowers/specs/2026-11-18-checklist-drag-appearance-design.md`.

## Ограничения

- Ручка располагается рядом с номером и полем; сами поля остаются однострочными.
- Сохранить нумерацию, удаление, добавление, фокус нового пункта, валидацию и payload API.
- Использовать один список: не добавлять демонстрационный второй список и межсписочный перенос.
- Удалить DataTable row-reorder, обработчики и стили native drag image.
- Не менять бизнес-логику, API, схему данных и права.
- Не запускать тесты, typecheck, сервер или браузер.

## Задачи

### 1. Подключить библиотеку и заменить список

- Добавить `vue-draggable-plus` в зависимости `apps/web`.
- Заменить DataTable на один `VueDraggable` с `v-model="steps"`, стабильным ключом `id` и ручкой `.checklist-step-drag-handle`.
- Оставить поля, кнопки действий, валидацию, ограничения и отправляемые данные без изменений.
- Удалить DataTable row-reorder события, native drag event типы/обработчики и canvas-превью.

### 2. Оформить состояния сортировки

- Задать именованные классы выбранной, перетаскиваемой и placeholder-строки.
- Включить fallback-перетаскивание и оставить копию читаемой, убрав фон, рамку и тень как у строки, так и у поля ввода.
- Отключить выделение текста на строках и drag-копии; обычное выделение текста в поле сохранить.
- Оставить placeholder прозрачным без отдельной цветной линии.
- Оставить область списка ограниченной по высоте с внутренней прокруткой.

### 3. Проверить изменения

- Сверить плотность и элементы формы с `UI_COMPONENT_STYLES.md`, `UI_AND_NAVIGATION.md` и `apps/web/app/features/team/components/TeamMembersTable.vue`.
- Отформатировать только изменённые файлы Prettier.
- Запустить targeted ESLint, `git diff --check` для файлов задачи и сборку `apps/web`.
- Не запускать тесты, typecheck, сервер и браузер.
