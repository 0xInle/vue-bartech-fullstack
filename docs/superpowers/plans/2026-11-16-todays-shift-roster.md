# Сводка смены на сегодня — план реализации

> **Для исполнителей:** реализовать план по шагам. Существующие пользовательские изменения сохранять.

**Цель:** добавить на главную заведения обзор сотрудников, назначенных на смену сегодня.

**Архитектура:** переиспользовать существующий API и типы месячного графика, выделив повторно
используемый запрос так, чтобы главная не загружала данные для управления графиком. Новый компактный
компонент отображает только сегодняшние смены и состояния загрузки/ошибки/пустого результата.

**Стек:** Nuxt 4, Vue 3, TypeScript, TanStack Vue Query, PrimeVue 4, Tailwind CSS.

**Спецификация:** `docs/superpowers/specs/2026-11-16-todays-shift-roster-design.md`

## Общие ограничения

- Не менять серверные права, бизнес-правила, API-контракт или модель графика.
- Главный экран сохраняет поиск продукции главным блоком.
- Показывать только текущую дату и записи со значением ячейки `SHIFT`.
- Не показывать переход к графику, выходные, отпуск, больничный, неявку и пустые назначения.
- В строке показывать имя, должность, тип смены и назначенное время; сортировать по времени начала.
- Следовать `UI_COMPONENT_STYLES.md` и сценарию главной в `UI_AND_NAVIGATION.md`.
- Не создавать и не запускать автоматические тесты; не запускать браузер или локальный сервер.

## На что обратить внимание при ревью

- Дата смены должна совпадать с датой ячейки графика, а не с индексом, зависящим от локали.
- Сотрудники без рабочей смены сегодня не попадают в список; пустая выдача не показывает счётчик
  назначений как работающую смену.
- Сортировка использует фактическое назначенное время; конец смены корректно переходит через
  полночь, если длительность выходит за границу суток.
- При переключении рабочего пространства запрос и список должны перейти на новое заведение.
- Ошибка загрузки сводки не должна скрывать или блокировать поиск продукции.
