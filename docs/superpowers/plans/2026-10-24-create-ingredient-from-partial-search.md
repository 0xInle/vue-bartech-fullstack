# Создание ингредиента из частичных результатов — план реализации

> **Для исполнителя:** выполнять задачи по порядку и соблюдать ограничения проекта.

**Цель:** дать возможность открыть создание локального ингредиента из выдачи с похожими результатами, если точного ингредиента нет.

**Архитектура:** вычислять точное совпадение среди предложенных результатов в `IngredientSelector` и передавать его в существующий слот подвала. В подвале Cocktails-компонентов сохранять список, показывать контекстное действие и переключать его на существующую форму создания.

**Технологии:** Vue 3, TypeScript, PrimeVue 4, Tailwind CSS.

**Спецификация:** `docs/specs/2026-10-24-create-ingredient-from-partial-search.md`.

## Общие ограничения

- Создание открывается одним нажатием; категория остаётся обязательной.
- Поисковые результаты остаются штатными вариантами выбора; CTA находится только в подвале AutoComplete.
- Точное совпадение сравнивать по нормализованным названиям ингредиентов (`INGREDIENT`), с приведением регистра, пробелов и `ё` к `е`.
- Не менять API, серверную логику и другие поля состава.
- Не создавать и не запускать тесты без отдельной команды пользователя.
- Визуально проверить dropdown по прямой просьбе пользователя; сохранить все посторонние изменения рабочей копии.

## Файлы

- `apps/web/app/features/products/components/IngredientSelector.vue` — вычисление точного совпадения ингредиента и передача флага в scoped slot `footer`.
- `apps/web/app/features/cocktails/components/CocktailComponentRows.vue` — действие в подвале при частичных результатах и сохранение списка опций.
- `UI_AND_NAVIGATION.md` — сценарное правило уже обновлено до начала реализации.

## Области внимания

- Совпадение другого типа продукта с запросом не скрывает создание ингредиента.
- При точном совпадении ингредиента кнопка создания скрыта.
- Частичные результаты остаются выбираемыми при открытой форме создания.
- В состоянии нулевой выдачи остаются текст «Ингредиент не найден» и действие создания.
- Загрузка и ошибка поиска не показывают действие преждевременно.
