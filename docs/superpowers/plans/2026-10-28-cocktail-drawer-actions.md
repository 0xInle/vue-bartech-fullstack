# Кнопки действий в карточке коктейля — план реализации

> **Для исполнителя:** выполнять план последовательно в текущем рабочем дереве. Не запускать тесты и браузерную проверку без отдельной команды пользователя.

**Цель:** показывать действия карточек коктейлей, заготовок и гарниров без иконок и полными подписями; в карточке коктейля сохранить один ряд без прокрутки и изменения размера Drawer; привести глобальный размер текста кнопок к принятому стандарту.

**Архитектура:** исправить базовый размер текста кнопок в общем CSS с 14 px на 12 px. Удалить иконки у повторяющихся действий во всех карточках продуктов. В карточке коктейля сохранить одинаковый внешний промежуток, убрать прокрутку и применить компактные внутренние отступы.

**Технологии:** Nuxt 4, Vue 3, PrimeVue 4, Tailwind CSS.

**Дизайн:** `docs/superpowers/specs/2026-10-28-cocktail-drawer-actions-design.md`.

## Ограничения

- Однострочная кнопка — высотой 32 px; текст каждой кнопки — 12 px.
- Убрать иконки у действий редактирования, скачивания и истории в трёх карточках; сохранить полные подписи и размер Drawer.
- Сохранить порядок действий, текущие проверки разрешений и варианты кнопок.
- Не менять иконки архивирования и других самостоятельных действий.
- Не создавать и не запускать тесты; не запускать браузер и визуальную проверку без прямой команды пользователя.
- Prettier запускать только на изменённых файлах.
