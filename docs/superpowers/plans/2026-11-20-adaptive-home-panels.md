# План блоков главной страницы

**Цель:** карточки главной занимают высоту по содержимому без общего адаптивного ограничения; длинные
списки прокручиваются внутри карточек, а пользователь может свернуть любой блок.

**Правила:** все блоки раскрыты по умолчанию. Задачи, чек-листы и объявления получают внутреннюю
прокрутку при количестве записей больше десяти. Последние изменения ограничены тремя записями.
Калькулятор не растягивается и не имеет ограничения высоты. Сворачивание плавное с учётом системной
настройки уменьшения движения.

**Файлы:** `VenueHomeScreen.vue`, `WorkspaceShell.vue`, `ProductCostCalculator.vue`, `VenueChecklists.vue`,
`TeamAnnouncements.vue`, `MyVenueReminders.vue`, `RecentAuditEvents.vue`, `TodayShiftRoster.vue`,
`main.css`, `UI_AND_NAVIGATION.md`.
