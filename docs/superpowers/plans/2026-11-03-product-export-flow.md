# План реализации потока выгрузки продукции

> **Исполнителям:** Обязательный навык: `superpowers:executing-plans`. Шаги отмечаются флажками `- [ ]`.

**Цель:** Формировать ZIP PDF по текущему поиску и фильтрам, удалить выбор чекбоксами и структурированные JSON-резервные архивы, сохранив PDF-выгрузки в сценариях закрытия.

**Архитектура:** Vue-экран формирует список ID из текущего отфильтрованного списка. Backend остаётся источником разрешений и области данных; при закрытии компании он формирует ZIP только с PDF по заведениям, доступным инициатору. Для этого добавляется новый тип выгрузки закрытия, старые значения enum остаются для исторических записей.

**Технологии:** Vue 3, Nuxt, PrimeVue, NestJS, Prisma, миграция enum PostgreSQL, сгенерированный OpenAPI-клиент, PDFKit и Archiver.

**Спецификация:** `docs/superpowers/specs/2026-11-03-product-export-flow-design.md`

## Общие ограничения

- Backend — единственный доверенный источник разрешений, области данных и бизнес-ограничений.
- Документация и пользовательские строки пишутся на русском языке.
- Не создавать и не запускать тесты; не запускать typecheck, сервер, браузер или визуальную проверку.
- Сохранять все имеющиеся изменения пользователя, особенно `.gitignore`.
- Соблюдать `UI_COMPONENT_STYLES.md`, сценарий выгрузки из `UI_AND_NAVIGATION.md` и образец экрана архива.

## Основные риски для ревью

- Выгружается ровно текущий результат поиска и фильтрации, а без условий — вся доступная загруженная продукция. Отдельный выбор карточек на странице отсутствует.
- Архивные карточки включаются только при наличии у пользователя соответствующего разрешения; серверная проверка области не ослабляется.
- Закрытие компании включает PDF только из серверного списка заведений, доступных инициатору; клиент не передаёт произвольный список заведений. Проверить построение области в сервисе жизненного цикла.
- Старые типы выгрузок остаются читаемыми в хранилище, но новые структурированные архивы не создаются и JSON не формируется для новых запросов.
- При пустом результате фильтра кнопка остаётся выключенной и запрос с пустым списком ID не отправляется.
