# Шаблоны смен через селекты — план реализации

Шаги отмечаются флажками `- [ ]` по мере реализации.

**Цель:** оставить создание шаблона смен в виде именованного упорядоченного списка дней, где каждый Select выбирает настроенный вариант смены или выходной.

**Архитектура:** изменения остаются во frontend графика. Каждая позиция формы хранит ID настройки заведения, `null` для выходного или незаполненное значение до выбора. Сохранение продолжает использовать существующий API; серверная модель, версии и назначения не меняются.

**Технологии:** Vue 3, Nuxt 4, PrimeVue 4, Tailwind CSS, существующие composable `useSchedule` и API.

**Спецификация:** `docs/specs/2026-10-26-shift-template-builder-design.md`.

## Общие ограничения

- В селекте показываются только настройки смен выбранного заведения и отдельная опция «Выходной».
- Цикл содержит от 1 до 31 дня и минимум одну смену; `null` обозначает выходной.
- При сохранении передаются только заполненные значения; незаполненные селекты блокируют сохранение.
- После успешного сохранения очищаются название и последовательность; список сохранённых шаблонов остаётся.
- Подсказка смены в таблице показывает только фактическое время начала и длительность в формате `17:00 | 6 ч`.
- Названия типов смен в UI: «Утро», «День», «Вечер», «Ночь»; в списке шаблонов показываются компактные цветные квадратные индикаторы последовательности.
- Не добавлять тестовую инфраструктуру/файлы и не запускать тесты, typecheck или браузерную проверку.
- Форматировать только изменённые файлы Prettier; допустимы ESLint и build.

## Проверка реализации

- Повторный день может выбрать тот же вариант смены, не меняя другие дни.
- Выходной выбирается как значение конкретного дня; кнопку добавления отдельного выходного не показывать.
- Новая строка начинается без выбора, имеет отдельное действие удаления; число строк ограничено 31.
- Номер строки отображается без слова «День»; крестик удаления скрыт, когда строка одна.
- Выбранный текст и пункты Select визуально совпадают с однотипными Select в проектных формах.
- Список сохранённых шаблонов показывает маркеры каждого дня цикла, hover смены — `HH:mm | N ч`.
- Пока нет настроек смен, добавление и сохранение недоступны и есть понятное объяснение.
- Моковый предпросмотр, редактирование шаблона, версии, назначения и список ранее созданных шаблонов продолжают работать.
