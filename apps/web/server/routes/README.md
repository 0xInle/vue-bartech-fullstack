# Публичные SEO-маршруты

Nitro-маршруты `robots.txt` и `sitemap.xml` описывают только публичные страницы IndieBar. Карта
содержит лендинг `/` и справку `/docs`; внутренние маршруты не включаются.

Абсолютные адреса формируются из `NUXT_PUBLIC_SITE_URL`, отдельной настройки origin публичного сайта.
Если значение отсутствует или некорректно, sitemap остаётся без URL, а robots.txt не публикует
ссылку на sitemap. Локальный `APP_ORIGIN` для этого не используется. Закрытые и персональные
маршруты получают `X-Robots-Tag: noindex, nofollow`; это указание поисковым роботам, а не механизм
авторизации.
