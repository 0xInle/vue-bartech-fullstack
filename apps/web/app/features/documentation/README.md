# Пользовательская документация IndieBar

Срез `documentation` отвечает за публичную справку для пользователей MVP. Страница помогает разобраться в создании рабочего пространства, приглашениях, ролях, нескольких местах работы, передаче ответственности, закрытии, продукции и обращении за помощью.

Маршрут `/docs` размещён в `app/pages/docs.vue`. Страница остаётся тонкой точкой входа и собирает `DocumentationScreen` из этого среза. Экран отображает список тем, текущую статью и содержание статьи; на узких экранах навигация открывается в PrimeVue `Drawer`.

Короткие тексты и их структура находятся в `content/documentation-articles.ts`. Они основаны на `MVP_SCOPE.md` и соответствующих предметных документах, перечисленных в `DOCUMENTATION_MAP.md`. Пользовательские статьи описывают только MVP и не раскрывают внутреннюю техническую реализацию.

Справка доступна без входа и открывается с лендинга. Поиск, редактирование статей и навигация из рабочего пространства в этот срез не входят.
