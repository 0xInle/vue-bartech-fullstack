# Архив продукции

Раздел показывает архивные карточки текущего заведения. Список, карточка только для чтения и диалоги
используют PrimeVue. Поиск и тип продукции отражаются в URL. Данные и ошибки операций принадлежат
`useProductArchive`; он вызывает только публичные операции сгенерированного API-клиента.

Чтение требует `view_archive`, а архивирование и восстановление — `manage_product_archive`.
Backend повторно проверяет права и область данных; скрытие действий в интерфейсе не является
защитой. Глобальные ингредиенты не архивируются. Активные локальные ингредиенты для архивирования
выбираются отдельным компактным поиском в архиве, без создания нового CRUD-раздела.

`ArchiveActionButton` — публичный вход раздела для действующих техкарт. Он показывает последствия
и активные зависимости ссылками, не меняет кеш при отказе. После успешной операции открывается
архивная карточка. Восстановление показывает полное дерево, допускает новое имя корневой или
вложенной карточки при конфликте, сохраняет решения при обновлении плана и требует повторного
явного подтверждения. Компоненты заменённой карточки скрываются и не отправляются серверу,
если к ним не ведёт другая восстанавливаемая ветвь. При замене гарнира нельзя повторно выбрать
гарнир, уже указанный в этом коктейле или выбранный для другой архивной строки. Замены
применяются только внутри фактически восстанавливаемых карточек.

После мутаций инвалидируются только запросы текущих компании и заведения. Создание,
редактирование, удаление, история и выгрузки в этот раздел не входят. Архивные карточки сохраняют
ссылки и доступны только для чтения.
