# Архив продукции

Раздел показывает архивные карточки текущего заведения. Список оформлен компактной таблицей на
компьютере и карточками на телефоне; PrimeVue `Paginator` показывает по 20 записей на страницу.
Поиск, тип продукции и номер страницы отражаются в URL. Карточка открывается в Drawer поверх
списка, который сохраняет свой контекст при закрытии. Данные и ошибки операций принадлежат
`useProductArchive`; он вызывает только публичные операции сгенерированного API-клиента.

Чтение требует `view_archive`, а архивирование и восстановление — `manage_product_archive`.
Backend повторно проверяет права и область данных; скрытие действий в интерфейсе не является
защитой. Ингредиенты — глобальные и локальные — не архивируются. Архив доступен для коктейлей,
заготовок и гарниров.

`ArchiveActionButton` — публичный вход раздела для действующих техкарт. Он показывает последствия
и активные зависимости ссылками, не меняет кеш при отказе. После успешной операции открывается
архивная карточка. Восстановление показывает полную необходимую цепочку архивных зависимостей и
восстанавливает её целиком после явного подтверждения. При конфликте названия пользователь
переименовывает конфликтующие карточки. Если цепочка изменилась до подтверждения, сервер возвращает
актуальный план, а пользователь проверяет его и подтверждает действие повторно. Замена зависимостей
в сценарии восстановления не предлагается.

`PermanentDeleteActionButton` используется в списках коктейлей, заготовок, гарниров, локальных
ингредиентов и архивных карточках. Если ссылок нет, показывается короткое подтверждение. При активных
использованиях пользователь задаёт одну замену для всех активных связей либо явно удаляет обратную
локальную цепочку; индивидуальные замены не настраиваются, архивные ссылки блокируют замену и остаются
только в варианте цепочки. Backend повторно
проверяет право, принадлежность, отпечаток графа, допустимость замен и каскад внутри транзакции.
Каждая изменённая карточка и каждая удалённая запись оставляют аудит.

Названия связанных продуктов из модалки удаления открывают общий Drawer просмотра без смены
маршрута. Архивные связанные продукты показывает `ArchiveProductDrawer` только для чтения. Из
самого списка архива этот Drawer также показывает закреплённые действия восстановления и
безвозвратного удаления по разрешениям сотрудника.

После мутаций инвалидируются только запросы текущих компании и заведения. Создание,
редактирование, аудит и выгрузки в этот раздел не входят. Архивные карточки сохраняют
ссылки и доступны только для чтения.
