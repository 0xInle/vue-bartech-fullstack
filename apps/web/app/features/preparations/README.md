# Заготовки

Модуль `preparations` реализует первый законченный сценарий заготовок текущего заведения:
список, технологическую карту по прямому адресу, создание и редактирование в Drawer. Страницы Nuxt остаются
тонкими контейнерами и подключают только экраны feature-модуля.

## Границы

- `PreparationListScreen.vue` отвечает за список, URL-состояние, фильтры и открытие Drawer.
- `PreparationCardScreen.vue` выводит технологическую карту и открывает редактирование только при праве `manage_products`.
- `PreparationFormDrawer.vue` координирует создание и редактирование, валидацию и обработку ошибок сохранения.
- `PreparationImpactDialog.vue` показывает названия и типы активной продукции, затронутой изменением заготовки.
- `PreparationComponentRows.vue` редактирует только строки состава и использует публичные
  компоненты `features/products`.
- `usePreparations.ts` владеет TanStack Query-запросами и ключами `preparation-list`,
  `preparation-card` и `product-references`, а также синхронизацией поиска, категории и
  сортировки с URL.

Маршруты: `/app/companies/:companyId/venues/:venueId/preparations` и
`/app/companies/:companyId/venues/:venueId/preparations/:preparationId`. Создание отдельного
маршрута не имеет: форма открывается только в Drawer. Редактирование открывается с сохранённой
техкарты и остаётся на ней после записи. Backend остаётся источником прав и ограничений области
данных; frontend показывает действия создания и редактирования только при `manage_products`.

При сохранении изменённой заготовки backend в одной транзакции проверяет прямые и косвенные
зависимости активной продукции текущего заведения. Если они есть, он возвращает список влияния
без записи. После подтверждения сервер повторно проверяет список и сохраняет только при
актуальном отпечатке; изменившийся список требует нового подтверждения. Неизменённая форма
не отправляется. Ошибки остаются вверху Drawer, введённые данные сохраняются.

После изменения HTTP-контракта API-клиент обновляется только штатной командой
`pnpm api:generate`; generated-файлы вручную не редактируются.
