# Выгрузка продукции

Feature `exports` позволяет сформировать PDF одной техкарты или ZIP PDF текущего результата поиска
и фильтрации. Без условий поиска и фильтров выгружается вся доступная продукция; отдельного выбора
карточек на странице нет. Продуктовые данные и правила доступа определяет backend; клиент
использует общий API-клиент и ключи TanStack Query с аккаунтом, компанией и заведением.

`ProductExportsScreen` показывает список продукции или состояние одного запроса из URL. Заголовок
страницы размещается в верхней строке `WorkspaceShell`, а действие пакетной выгрузки — рядом с
поиском и фильтрами. Повторных
запросов/истории файлов экран не загружает. Готовая выгрузка скачивается через новую
краткоживущую ссылку API. `ExportActionButton` начинает PDF-выгрузку из карточек коктейля,
заготовки и гарнира. Требования к срокам, содержимому и фоновому процессу описаны в
[`спецификации этапа 8`](../../../../../docs/specs/2026-10-15-stage-8-product-exports-design.md).

`ClosureExportPicker` запрашивает ZIP всех доступных техкарт заведения при закрытии; список и
состав карточек определяет backend. Выгрузка необязательна и не блокирует закрытие. При закрытии
компании он запрашивает один ZIP только с PDF техкарт всех доступных инициатору заведений; список
заведений определяет backend. Структурированных резервных архивов и обратного импорта нет.
`ClosureOperationScreen` читает только итог собственной операции и получает краткоживущую ссылку
на привязанный файл, если его исходный срок хранения ещё не истёк.
