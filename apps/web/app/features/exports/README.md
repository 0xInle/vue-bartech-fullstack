# Выгрузка продукции

Feature `exports` позволяет сформировать PDF одной активной техкарты, ZIP выбранных PDF или
структурированную резервную ZIP-копию продукции текущего заведения. Продуктовые данные и правила
доступа определяет backend; клиент использует общий API-клиент и ключи TanStack Query с аккаунтом,
компанией и заведением.

`ProductExportsScreen` показывает выбор карточек или состояние одного запроса из URL. Повторных
запросов/истории файлов экран не загружает. Готовая выгрузка скачивается через новую
краткоживущую ссылку API. `ExportActionButton` начинает PDF-выгрузку из карточек коктейля,
заготовки и гарнира. Требования к срокам, содержимому и фоновому процессу описаны в
[`спецификации этапа 8`](../../../../../docs/specs/2026-10-15-stage-8-product-exports-design.md).

`ClosureExportPicker` создаёт PDF, ZIP выбранных PDF или резервный ZIP заведения только с
идентификатором операции закрытия. Для компании backend формирует один ZIP из раздельных резервных
пакетов доступных заведений. `ClosureOperationScreen` читает только итог собственной операции и
получает краткоживущую ссылку на привязанный файл, если его исходный срок хранения ещё не истёк.
