# Команда компании и заведения

Срез `team` показывает состав выбранного заведения, доступное управление участниками и приглашения. `TeamManagementScreen.vue` собирает экран: сотрудникам соответствует компактная PrimeVue `DataTable`, а кнопка «Пригласить» открывает общий Drawer с формой и ожидающими приглашениями.

Приглашение шеф-бармена и приглашения сотрудников заведения используют разные API и области членства. `useCompanyChefTeam` обслуживает компанию, `useVenueTeam` — текущее заведение. Форма предлагает только должности, разрешённые для текущего пользователя, а обработчик направляет запрос по выбранной должности. Отзыв приглашений также вызывает API соответствующего контекста. Создание нового заведения остаётся в срезе управления заведениями.

`TeamMemberList` выводит ФИО и должность компактным PrimeVue `Tag`; email и ролевые пояснения в таблице не показываются. Выбор управляемой строки открывает `TeamMemberEditorDrawer`, где доступны должность и делегируемые разрешения; сервер повторно проверяет полномочия и правила управления. `useVenueTeam` загружает членов команды и приглашения, создаёт и отзывает приглашения, изменяет сотрудника. `useCompanyChefTeam` обслуживает приглашения шеф-барменов на уровне компании.

Список шеф-барменов компании на странице команды не отображается. Пример ожидающего приглашения включается только в режиме разработки, помечается как пример и не участвует в запросах или действиях над реальными приглашениями.

Оба вида приглашений проходят публичный поток `/invitations`: токен остаётся во fragment до чтения клиентом и не попадает в HTTP URL, а членство создаётся только после завершения регистрации или входа. Приглашение шеф-бармена создаёт роль уровня компании без локального членства; остальные должности относятся к выбранному заведению. Сроки, состояния и обработка конфликтов описаны в `REGISTRATION_FLOW.md`, состав ролей — в `ROLES_AND_PERMISSIONS.md`, а технические поля — в `DATA_MODEL.md`.

Бизнес-правила ролей и областей доступа описаны в [ROLES_AND_PERMISSIONS.md](../../../../../ROLES_AND_PERMISSIONS.md); актуальное представление экрана — в [UI_AND_NAVIGATION.md](../../../../../UI_AND_NAVIGATION.md).
