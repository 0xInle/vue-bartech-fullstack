# Внутренний журнал действий

Функция показывает служебные события IndieBar сотрудникам с разрешением `internal_audit`. Экран
дожидается проверки внутренней сессии и не запрашивает журнал без нужного разрешения.

`InternalAuditScreen` отображает тип и время события, тип или email внутреннего актора и доступные
ID области или служебной сессии. `useInternalAudit` загружает API-страницы по 50 записей и продолжает
их по непрозрачному курсору. API не выдаёт произвольные метаданные и клиентские события; подробности
контракта описаны в `UI_AND_NAVIGATION.md`.
