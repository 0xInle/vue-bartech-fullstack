# Продуктовая аналитика

Публичная часть feature отправляет только закрытые события использования продукции и поиска через
`useProductAnalytics`. Тексты запросов, содержимое карточек и идентификаторы пользователей,
компаний и заведений не передаются. Сбой доставки не влияет на пользовательское действие.

Внутренний экран загружает только агрегаты за период до 90 дней и запрашивает API лишь после
проверки внутренней сессии и разрешения `product_analytics`. Сервер остаётся источником проверки
разрешения. Состав событий и границы данных определены в `MVP_SCOPE.md` и `ARCHITECTURE.md`.
