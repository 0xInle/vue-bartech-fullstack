# Помощь и обращения

Срез `support` обслуживает форму обращения, список и переписку текущего пользователя. Он не
открывает сотрудникам IndieBar доступ к продукции и передаёт все проверки авторства backend.

`useSupportRequests` использует сгенерированный API-клиент, а `useSupportConversation` читает и
отправляет сообщения, вложения, отметку прочтения и подтверждение запроса временного доступа.
`useSupportUnreadCount` обновляет индикатор непрочитанного раз в минуту и после действий с перепиской.
Состояние отображается числовым `Badge` размера `small` справа от пункта меню. В таблице для него
выделена отдельная колонка непосредственно перед статусом, ширина которой определяется содержимым
бейджа, чтобы чипы оставались выровненными независимо от наличия непрочитанных сообщений. При
нулевом счётчике бейдж скрывается, колонка сохраняет ширину. При открытии переписки `markRead`
вызывает API и инвалидирует счётчик; индикаторы исчезают после обновления от backend.
Скачать файл можно только после статуса `clean`; API выдаёт краткоживущую ссылку после проверки
авторства.
При действующем grant интерфейс скрывает повторные действия запроса и подтверждения доступа.

Временный доступ подтверждается в сообщении `access_request`; пользователю показывается срок до
семи дней, а backend определяет область по текущей роли. Для бар-менеджера обращение связано с
открытым заведением, его название в карточке согласия не дублируется. Решение об области и выборе
заведения для интерфейса шеф-бармена отложено до проектирования этого сценария. После выдачи фактический
срок действия и действие отзыва показываются отдельной строкой вне прокручиваемой истории, над полем
ответа. Доступ может отозвать пользователь или поддержка; обращение закрывается поддержкой после отзыва
или истечения grant и отправки итогового сообщения.

Канонический маршрут страницы — `/app/companies/:companyId/venues/:venueId/support`.
`SupportPageScreen` загружает рабочее пространство по route params через `useVenueWorkspace` и
всегда размещает экран внутри `WorkspaceShell`. Старый `/app/support` перенаправляет по переданным
company/venue ID либо в единственное доступное рабочее пространство; если контекст неоднозначен,
пользователь возвращается к выбору пространства.

Причина обращения изначально не выбрана, а исходное сообщение ограничено 1000 символами.
Клиентские ответы также ограничены 1000 символами; внутренние ответы поддержки остаются до 5000.

Правила формы, форматов и количества файлов, а также хранения описаны в
[`спецификации обращений`](../../../../../docs/specs/2026-10-16-stage-9-support-requests-design.md).
