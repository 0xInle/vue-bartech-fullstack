# Помощь и обращения

Срез `support` обслуживает форму обращения клиента и список обращений текущего пользователя. Он
не открывает сотрудникам IndieBar доступ к продукции и передаёт все проверки авторства backend.

`useSupportRequests` использует сгенерированный API-клиент, обновляет список после отправки и
повторно запрашивает обращения, пока сервер проверяет вложение. Скачать файл можно только после
статуса `clean`; API выдаёт краткоживущую ссылку после проверки авторства.

`useSupportAccessGrants` отдельно загружает собственные временные доступы, выдаёт их только после
подтверждения пользователя и отзывает по его команде. Срок и область определяет backend по текущей
роли: бар-менеджер — своё заведение, шеф-бармен — всю компанию.

Страница `/app/support` — точка композиции экрана. Текущая компания и заведение могут передаваться
из рабочей оболочки как контекст; сервер проверяет принадлежность пользователя.

Правила формы, допустимых файлов и хранения описаны в
[`спецификации обращений`](../../../../../docs/specs/2026-10-16-stage-9-support-requests-design.md).
