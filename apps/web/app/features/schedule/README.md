# График сотрудников

Срез `schedule` показывает плановый график выбранного заведения за месяц внутри страницы команды. `ScheduleScreen` получает рабочее пространство, а `useSchedule` читает месячные данные и шаблоны, изменяет ячейки, формирует или продлевает график, сохраняет комментарии и выгружает PDF/XLSX. Полномочия определяются разрешением `manage_schedule`; клиент не заменяет серверную проверку доступа.

Таблица использует PrimeVue `DataTable`: дни месяца, сотрудник, должность и итоги. Ctrl/Command-клик выбирает отдельные применимые ячейки для массового редактирования; клик по ФИО добавляет или снимает выбор всех применимых дней строки. Пустые дни остаются пустыми. Общий Drawer формирования и продления использует PrimeVue `SelectButton` в заголовке для переключения режима. Формирование сохраняет назначение только выбранным сотрудникам; продление продолжает отмеченные циклы по сохранённым версиям и датам привязки, оставляя заполненные ячейки без изменений. Если среди выбранных сотрудников нет назначения цикла, сервер возвращает ошибку и не изменяет график ни для кого из набора. Список и назначения в Drawer соответствуют выбранному целевому месяцу.

В режиме разработки страница показывает 11 демонстрационных сотрудников. Их циклы, статусы и шаблоны работают только в памяти браузера. Для проверки ожидания ответа режим имитирует задержку около 450 мс при загрузке месяцев, списка Drawer и операциях записи. При переключении месяца таблица остаётся смонтированной и показывает прежние данные под локальным LoadingOverlay со Spinner; Drawer формирования ограничен высотой окна, прокручивает список сотрудников внутри и показывает такой же overlay при загрузке. Изменения моков пропадают после перезагрузки.

Кнопка управления шаблонами открывает Drawer со списком пользовательских циклов и действиями создания, редактирования и удаления. Изменение параметров создаёт новую версию, а простое переименование оставляет версию прежней. Удаление требует подтверждения и снимает назначения шаблона, но не очищает уже заполненные дни графика или их историю.
