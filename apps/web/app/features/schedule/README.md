# График сотрудников

Срез `schedule` отображает плановый график выбранного заведения за месяц. `ScheduleScreen` собирает таблицу, настройки типов смен, редакторы дня и цикла, массовые действия и выгрузку; `useSchedule` читает и изменяет данные через API. Сервер остаётся источником полномочий и бизнес-ограничений.

В заведении включается любое подмножество четырёх фиксированных типов У/Д/В/Н с настройками времени начала и длительности. Ячейка хранит снимок значений и допускает их переопределение. Шаблон задаёт повторяемую последовательность длиной до 31 дня, где каждый день — тип смены либо выходной. Генерация и продление рассчитывают день относительно даты привязки цикла. Значения итогов суммируют длительность смен.

В том числе в режиме разработки экран использует реальные данные API для сотрудников, графика, настроек смен и шаблонов. Новая ячейка графика изначально пуста; настройки смен и циклические шаблоны принадлежат выбранному заведению.
