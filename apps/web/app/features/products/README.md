# Выбор продукции

Feature `products` содержит клиентский поиск и минимальный элемент выбора ингредиента для форм,
которые будут реализованы на следующем продуктовом этапе. Здесь нет страницы или отдельной
навигации.

## Части

- `composables/useProductSearch.ts` выполняет запрос через сгенерированный API-клиент, передаёт
  сигнал отмены и держит результат в TanStack Query с ключом, включающим компанию и заведение.
- `components/IngredientSelector.vue` связывает поле PrimeVue AutoComplete с поиском и возвращает
  выбранную типизированную карточку через `v-model`.

Поиск вызывается после двух символов; задержка ввода задаётся компонентом. Backend повторно проверяет
доступ и возвращает только глобальные ингредиенты и локальные продукты текущего заведения.
Обновление контракта выполняется через `pnpm api:generate`; generated-код нельзя править вручную.
Operation-функции и модели доступны через публичный barrel `@bartech/api-client`. Файл
`packages/api-client/src/index.ts` не генерируется Orval и связывает сгенерированные operations и
модели, поэтому публичные типы остаются доступны после повторной генерации. `types.ts` выводит из
operation-ответов общие для компонентов поиска типы без дублирования DTO.
В нём также нормализуется `venueId` результата поиска: в текущем OpenAPI-контракте nullable-поле
описывается слишком широко, а интерфейс работает только со строковым идентификатором или `null`.
