# Внутренняя очередь поддержки

Срез `internal-support` показывает обращения и позволяет сотруднику IndieBar назначить активного
внутреннего сотрудника, изменить статус и скачать только чистые вложения. Экран скрывает очередь
без разрешения `support_requests`, а backend повторно проверяет внутреннюю сессию и разрешение на
каждом запросе.

`useInternalSupportQueue` вызывает сгенерированный API-клиент и обновляет очередь после изменений.
Данные компании или продукции из этого среза не загружаются; обращение не выдаёт временный доступ.

Пользовательские и внутренние правила описаны в
[`спецификации обращений`](../../../../../docs/specs/2026-10-16-stage-9-support-requests-design.md).
