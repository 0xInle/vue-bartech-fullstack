# Установка, обновление и состояние сети PWA

Срез PWA отвечает за установку приложения из профиля и предложение установить новую версию. Он
использует `$pwa` модуля `@vite-pwa/nuxt`; серверная отрисовка и режим разработки без этого объекта
не показывают PWA-действия.

`AccountProfilePanel` показывает установку только после события поддержки установки браузером и
скрывает действие для установленного приложения. Выбор «Не сейчас» вызывает
штатный `cancelInstall`, который сохраняет отказ в localStorage по ключу из `nuxt.config.ts`.

`PwaUpdatePrompt` подключён в корневой композиции Nuxt и доступен на всех страницах. Он предлагает
применить ожидающую версию только после `needRefresh`; обновление запускается пользователем. Закрытие
плашки скрывает её локально, не сбрасывая состояние обновления, поэтому её можно применить позднее
после нового появления.

Service worker и precache ограничены настройкой `workbox.globPatterns` в `apps/web/nuxt.config.ts`.
Этот срез не кеширует API или данные продукта и не обеспечивает работу с изменениями без сети.

`NetworkStatusBanner` показывает постоянное сообщение при потере сети. `useNetworkStatus` читает
`navigator.onLine` после гидрации и отслеживает события `online` и `offline`. На общей границе
`useApiFetch` отклоняет изменяющие запросы до отправки; `GET`, `HEAD` и `OPTIONS` остаются доступны.
Локальная очередь, офлайн-чтение бизнес-данных и кеширование API не реализованы.
