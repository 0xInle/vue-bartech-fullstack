# Первичная регистрация

Срез `registration` отвечает за сквозной процесс регистрации нового пользователя и подтверждение почты. В него входят данные первой компании и первого заведения, поскольку они вводятся в рамках этого процесса.

`useRegistrationFlow` хранит поля и шаги регистрации, проверяет совпадение пароля с его подтверждением на клиенте и выполняет запросы регистрации. Подтверждение пароля используется только в интерфейсе и не входит в запрос API. `RegistrationForm` и `EmailConfirmationForm` отвечают только за отображение соответствующих форм.

На лендинге регистрационная форма открывается кнопкой «Зарегистрировать компанию». Она запрашивает данные в порядке: компания, первое заведение, ФИО, электронная почта, пароль, подтверждение пароля. После отправки формы сохраняется прежний шаг подтверждения почты.

После подтверждения адреса API возвращает адрес перехода; срез передаёт его навигации. Последующее создание компаний и заведений относится к `organizations`, а вход и сессии — к `identity`.

Предметные правила регистрации определяются `REGISTRATION_FLOW.md`; реализация не дублирует серверные проверки.
