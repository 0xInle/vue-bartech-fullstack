# Временный служебный доступ к продукции

Срез позволяет внутреннему сотруднику с разрешением `service_access` выбрать действующий grant,
начать ограниченную сессию, перейти к продуктовым данным одного заведения и завершить сессию.
Пользовательская сторона выдаёт grant после отдельного подтверждения и может отозвать его.

`useInternalServiceAccess` загружает доступы и выполняет команды запуска и завершения с учётом CSRF.
`InternalServiceAccessScreen` показывает область и срок действия, активные сессии и доступные заведения
для company-grant. `InternalServiceProductsScreen` отображает область сессии, позволяет искать и
просматривать продукцию, создавать локальные ингредиенты, заготовки, гарниры и коктейли, а также
редактировать локальные ингредиенты и составные карточки. Формы составных продуктов остаются в своих
feature-папках; для служебного контекста API-запросы этих форм направляются на внутренние маршруты.
Ключи кеша включают идентификатор служебной сессии и не разделяются с клиентской рабочей областью.
Backend проверяет доступ и область при каждом запросе; клиентская навигация не считается полномочием.

Операции и сроки определены в `MVP_SCOPE.md`, `DATA_MODEL.md` и плане
[`временного служебного доступа`](../../../../../docs/plans/2026-10-16-stage-9-service-access.md).
