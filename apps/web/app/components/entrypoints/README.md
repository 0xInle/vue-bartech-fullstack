# Публичная точка входа

Каталог содержит визуальную оболочку лендинга и повторно используемые элементы публичного экрана. `PublicEntryScreen.vue` собирает брендовый блок, кнопки действий и нужную форму; состояние регистрации, входа и восстановления пароля остаётся в `usePublicEntryFlow` и профильных срезах.

На первом экране показывается только брендовый блок. Выбор регистрации или входа открывает форму справа и перемещает брендовый блок в левую колонку. Vue `TransitionGroup` анимирует перемещение и появление панели; на узких экранах элементы располагаются вертикально, а при `prefers-reduced-motion` переход почти мгновенный. Возврат к лендингу закрывает панель и перемещает брендовый блок обратно.

Успешный вход и состояние сессии отображаются в той же панели. Восстановление пароля остаётся частью сценария входа. Предметные правила и запросы принадлежат срезам `identity`, `registration` и `organizations`.
