# Межраздельные компоненты

Каталог содержит композиционные компоненты верхнего уровня приложения, которые связывают
несколько feature-модулей, не перенося их запросы и правила внутрь себя.

`WorkspaceProductDrawer.vue` показывает связанную карточку из окна безвозвратного удаления поверх
текущего рабочего экрана. Цель открытия хранится в `useWorkspaceProductDrawer`; для активного товара
используется Drawer соответствующего feature-модуля, для архивного — read-only Drawer архива.
Закрытие снимает overlay, не меняя маршрут и сохраняя нижнее окно удаления.
