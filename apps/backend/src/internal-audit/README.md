# Внутренний журнал действий

Модуль предоставляет сотрудникам IndieBar только постраничный просмотр `InternalAuditEvent`. Каждый
запрос требует действующую внутреннюю сессию и разрешение `internal_audit`.

API `GET /api/v1/internal/audit-events` выдаёт события от новых к старым с курсором по времени и ID.
Ответ намеренно выбирает только тип события, время, тип актора, email внутреннего актора и ID области
или служебной сессии. `metadata`, внешний `actorId` и клиентский `AuditEvent` модулем не читаются.

Схема ответа описана DTO для OpenAPI; просмотр не меняет и не удаляет события.
