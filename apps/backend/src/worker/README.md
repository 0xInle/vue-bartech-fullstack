# Фоновые обработчики приложения

Каталог содержит модули и обработчики задач, которые запускаются только в отдельном worker-процессе.
`CompanyLifecycleWorker` периодически выбирает компании с наступившим сроком закрытия и передаёт
сервису организаций атомарную проверку дедлайна, закрытие приглашений, аудит и удаление компании.
Повторный запуск безопасен: обработчик повторно проверяет состояние под блокировкой строки.

Очистка экспортных файлов выполняется экспортным worker из `packages/backend-exports`. Для удаления
области он сохраняет независимые tombstone-записи и повторяет удаление ключей. Их срок жизни не
ограничен фиксированным окном, пока нельзя доказать, что уже начатая S3-запись завершиться не может.
Правила закрытия определяются `COMPANY_AND_VENUE_LIFECYCLE.md` и планом текущего среза.

`SupportAttachmentWorker` в `@bartech/backend-support` независимо читает outbox вложений,
передаёт приватный поток ClamAV и отмечает файл проверенным либо отклонённым. До состояния `CLEAN`
API не выдаёт ссылку на скачивание; технические ошибки не включают содержимое файла или ответ
сканера в логи.
